Response Detective 95 — Progressive Difficulty Edition

Unzip the entire folder, then open index.html in Chrome.

15 cases are sequenced from simpler literal evidence to multi-step explanation and complex inference. Cases 1–5 Rookie, 6–10 Junior, 11–15 Master. Teacher approval unlocks the next case.

Existing progress from the prior Classroom/Unlockable edition is migrated by story identity when browser storage is accessible from the same origin. Important: opening a different local file path may create a different browser storage origin; do not assume saved progress automatically follows the ZIP.
